# @sisig/api

Shared data layer for the Sisig apps: the typed Supabase client, TanStack Query
setup, query keys, hooks and the backend error contract.

**Read [CONVENTIONS.md](./CONVENTIONS.md) before adding an RPC, hook or error code.**
It covers RPC naming, idempotency keys, pagination, timestamps, schemas,
query keys and the error codes. Database rules are in
[supabase/CONVENTIONS.md](../../supabase/CONVENTIONS.md).

## What it exports

- `createSupabaseClient`: the typed client (`Database` from `src/database.types.ts`,
  generated by `pnpm db:types`; never edit it by hand).
- `createQueryClient`, `keys` and the persisted-key allowlist.
- Hooks such as `useMenuCategories` and `useCreateOrder`.
- Errors: `normalizeError`, `normalizeErrorAsync`, `AppError`, `DomainError`,
  `isDomainError`, `DOMAIN_ERRORS` and `isRetryableError`.

## Scripts

```bash
pnpm --filter @sisig/api test       # Jest, including the error-code drift test
pnpm --filter @sisig/api typecheck
pnpm --filter @sisig/api lint
pnpm --filter @sisig/api build      # emits dist/, which the apps import
```
